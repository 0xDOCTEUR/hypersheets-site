# Hypersheets Omni Helper (Chrome extension)

**v2.2.0** — CGU-safe Hypersheets widget.

## Affichage
- **Clic icône** → panneau latéral Chrome (droite)
- Bouton **Autre écran** / **Écran** → fenêtre libre Windows (barre de titre) → glisse sur un 2ᵉ moniteur
- Overlay flottant sur les pages (toujours là)

## Données
- Imports locaux Hypersheets + marks publics Omni + positions HL publiques
- Referral Omni affiché : `OMNILGUPC6GM`

## Setup
1. `chrome://extensions` → Reload
2. Clique l’icône Hypersheets dans la barre Chrome
3. Le widget s’ouvre à droite ; tu peux élargir/réduire le panneau Chrome
